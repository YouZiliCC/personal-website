# 个人网站项目

这是一个现代化的个人网站项目，展示个人作品和信息。

## 📁 项目结构

```
personal-website/
├── index.html              # 主页面
├── styles/
│   └── main.css           # 主样式文件
├── scripts/
│   └── main.js            # 主JavaScript文件
├── assets/                 # 资源文件夹（图片、图标等）
├── package.json           # 项目配置
├── .gitignore            # Git忽略文件
└── README.md             # 项目文档
```

## ✨ 功能特性

- 📱 **响应式设计** - 完美适配各种设备
- 🎨 **现代化风格** - 使用现代CSS和设计模式
- ⚡ **流畅动画** - 平滑的页面交互
- 🔍 **SEO友好** - 搜索引擎优化
- 🌐 **跨浏览器兼容** - 支持主流浏览器

## 🚀 快速开始

### 本地开发

1. 克隆项目
```bash
git clone https://github.com/YouZiliCC/personal-website.git
cd personal-website
```

2. 启动本地服务器
```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js (需要安装 http-server)
npx http-server
```

3. 在浏览器中打开
```
http://localhost:8000
```

## 📝 页面部分

### 导航栏
- 主页、关于、项目、联系链接

- 欢迎信息和行动按钮

- 支持3列响应式布局

### 联系部分

- 邮箱和消息输入

### 页脚
- 版权信息

## 🎯 自定义指南

### 修改内容
编辑 `index.html` 文件中的文本内容：
- 更改标题和描述
- 更新项目信息
- 修改联系方式

### 修改样式
编辑 `styles/main.css` 文件：
- 修改颜色变量（--primary-color 等）
- 调整间距和大小
- 自定义响应式断点

### 添加功能
编辑 `scripts/main.js` 文件：
- 增强交互功能
- 集成第三方API
- 添加表单验证

2. 选择 `main` 分支作为源
3. 网站将自动部署到 `https://youzilic.github.io/personal-website`
